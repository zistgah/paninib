# Roadmap after v1.0

v1.0 established the platform. Subsequent releases add scientific depth
without removing existing capability.

## v1.1
Bind a real reference/annotation provider without compiler changes.

## v1.2
Optional genuine GPU kernels with CPU≈GPU tests, if hardware exists.

## v1.3
Richer developmental / morphogenetic models as domain plugins.

## later
Quantitative genetics, mammalian biochemical networks, physiology models,
validation datasets, observation providers, implicit geometry.

SSA, GPU, and two-tail genomic realization remain scientifically or
computationally constrained as documented in docs/v1.0-limitations.md.
