# On the name PANINI

This genetic compiler is a second, unrelated PANINI from the prompt-cycle
language already in the AyeAI estate.

I will not decide DOI minting. Until you say otherwise this tree stays
labelled **PANINI genetic compiler** as a *working title*, with the
recommendation that it receive its own name before a DOI is minted if
you do not intend Genetic CISC to be a target of the existing engine.

Two options, both valid:

1. **Domain of the existing language.** Genetic CISC becomes a backend
   of the prompt-cycle engine. The name stands. This repository becomes
   a target description plus runtime.
2. **Separate system.** Pick a new name now. Keep the three invariants.
   Do not share a DOI stem.

This file exists so the question cannot be buried in a README paragraph.
