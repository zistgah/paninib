# PANINI v1.0 limitations

Classification vocabulary is normative.

## IMPLEMENTED

Executable and tested: parser, semantic IR, biological resolution, CISC
catalogue + specs, RISC lowering records, Sequence IR, REPLACE/INSERT/DELETE/
SUBSTITUTE engine, reference genome engine (fixture + retrieved loci),
genotype compiler, knowledge registry, constraint graph/solver, biochemical
ODE engine, CPU reference backend, SSA Gillespie fixture, spatial fields,
reaction-diffusion fixture, cellular/developmental fixtures, phenotype
engine, physiological tank fixture, point-cloud/voxel/parametric/mesh
geometry, animation + glTF-min, realization planning, verification matrix,
artifact debugger, digital/physical vertical slices, CLI, seed.sh.

## MODELLED

Executable scientific/reduced-order model: `mouse_axial_1d`,
`mouse_axial_2axis`. These are planning twins, not validated embryos.

## FIXTURE

A→B→C kinetics, RD source/decay, cell-line fixture, tank physiology,
schematic geometry, mock generative provider, inverse fixture strategy,
SSA integer-count chain, composition stack.

## PROVIDER-DEPENDENT

Architecture exists; capability depends on an external provider:
NCBI/Refget HTTP, generative foundation model, organism plugins beyond
mouse + conformance, validation datasets, observation providers.

## SCIENTIFICALLY UNRESOLVED

The compiler correctly refuses to assert a causal result:

- genomic realization of "two tails"
- licensed inverse-causal biology beyond fixtures
- mammalian biochemical / physiological / morphogenetic validity
- experimental validation of any designed sequence
- quantitative genetics
- whole-organism digital twin

## NOT IMPLEMENTED

- Genuine CUDA kernels (GPUBackend.status = UNAVAILABLE)
- Implicit-surface / skeleton geometry engines
- Wet-lab vendor adapters / ordering
- Nested `{ }` block syntax beyond the line-oriented MVP
- GFF3 feature resolution against a live assembly
