# PANINI v1.0 specification

Copyright © 1993–2026 Abhishek Choudhary. All rights reserved. · AyeAI

Compiler `1.0.0`. This document is normative for the v1.0 research platform.

## Purpose

v1.0 is a coherent, reproducible, executable research platform. It finishes
the computational spine so researchers can compile, inspect, extend, test,
and publish against PANINI. It does not solve biology.

## Pipeline

```
PANINI source
  → parsing / semantic analysis
  → biological resolution
  → CISC → RISC → Sequence IR
  → reference sequence
  → derived sequence where justified
  → digital execution
  → molecular / spatial / cellular / developmental state
  → phenotype → geometry → animation
  → verification → debug trace
  → observation / validation representation
  → knowledge update → recompilation
```

Separately:

```
GenotypeDesign → RealizationPlan → RealizationPackage
  → physical/laboratory adapter boundary
```

The laboratory is an external realization substrate, never a Core backend.

## Frozen contracts

Every listed contract is versioned independently of the compiler number.

| Contract | Version field |
|---|---|
| PANINI language | LANGUAGE_VERSION |
| semantic IR | SEMANTIC_VERSION |
| biological resolution IR | RESOLUTION_VERSION |
| CISC | CISC_VERSION / ISA_VERSION |
| RISC | RISC_VERSION |
| lowering | LOWERING_VERSION |
| Sequence IR | SEQUENCE_IR_VERSION |
| GenotypeDesign | GENOTYPE_COMPILER_VERSION |
| ReferenceGenome | REFERENCE_CONTRACT_VERSION |
| KnowledgeProvider / ModelProvider | PROVIDER_VERSION / KNOWLEDGE_SPINE_VERSION |
| DigitalExecutionBackend | DIGITAL_BACKEND_VERSION |
| Geometry / Animation backends | GEOMETRY_BACKEND_VERSION |
| RealizationPlanningBackend | PHYSICAL_BACKEND_VERSION |
| Observation / ValidationRegistry | VALIDATION_VERSION |
| ExperimentalIR / ResolutionWorkOrder | EXPERIMENTAL_IR_VERSION |
| ArtifactGraph / ArtifactDebugger | ENGINE_VERSION |
| Provenance / Evidence / Capability registry | as emitted on artifacts |

Compatibility policy: additive minor changes; breaking changes require a
major bump of the affected contract. Do not collapse all identities into
one number.

## Invariants

1. Core remains organism-independent.
2. Models/providers/backends are selected by capability contracts.
3. Adding a valid knowledge record can close a diagnostic without compiler edits.
4. Desired ≠ predicted ≠ observed ≠ validated.
5. Causal basis ≠ validation status.
6. Unresolved is a first-class result.
7. Fixtures are labelled fixtures.
8. Declared backends execute at least one deterministic reference case or are marked UNAVAILABLE / CONTRACT_ONLY.
9. External laboratories are adapters.
10. No encyclopedia requirement.

## Sequence compiler

Justified sequence operations (REPLACE, INSERT, DELETE, SUBSTITUTE) produce
Sequence IR and an ATGC artifact deterministically. Unsupported operations
remain unsupported. Derived sequences carry parent digest, derived digest,
assembly, reference identifier, edit list, coordinate system, compiler
version, Sequence IR version, provenance, and validation status.

## Honesty

PANINI may compile what it can justify. It must represent what it cannot
justify as unresolved rather than silently converting hypothesis into sequence.
