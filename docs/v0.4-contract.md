This is the implementation contract for this revision. Nothing below is a
scaffold ticket. Each item has an executable acceptance test.

## What this revision will not do

- Authorise laboratory synthesis or animal work.
- Invent nucleotide strings.
- Declare a two-tail program SATISFIED on a one-axis model.
- Pretend V13 uncertainty propagation exists.
- Collapse CISC into the 16-operation RISC basis.

Physical execution remains `authorization.authorized = false`.
