# PANINI v0.8 — Core architecture completion

Copyright © 1993–2026 Abhishek Choudhary. All rights reserved. · AyeAI

v0.8 completes the compiler / execution / realization / validation spine
that v0.7 established. It does not claim biological maturity for every
backend.

## 1. What v0.7 provided

Per-constraint BiologicalResolutionEngine; diagnostics E0001–E0011;
ExperimentalIR and ResolutionWorkOrder; partial compilation; knowledge-growth
invariant; generative *interface* (unavailable by default); association ≠
causation (E0010); USER_ASSERTED remains NOT_VALIDATED; two-tail mouse remains
DESIGN_UNRESOLVED.

## 2. What v0.8 adds

Executable backend contracts and typed artifacts for:

- GenerativeModelProvider (complete contract + mock)
- configurable provider routing + provenance traces
- inverse-resolution contract (E0010 retained)
- ConstraintGraph
- first-class GenotypeDesign fields
- PhysicalRealizationBackend (local mock)
- DigitalExecutionBackend (existing simulator adapter)
- geometry / animation artifacts
- Observation, EvidenceRecord, claim history
- dual-path orchestration sharing one design
- SBOL export boundary (minimal fixture)
- hashed artifact graph

## 3. Backend contracts

PhysicalRealizationBackend: capabilities, realize, inspect, verify, provenance.
DigitalExecutionBackend: capabilities, execute, inspect, checkpoint, provenance.
GeometryBackend / AnimationBackend: phenotype → SpatialPhenotype → GeometryArtifact
and PhenotypeTrajectory → AnimationArtifact.
RealizationExporter: SBOL-minimal fixture.

No laboratory vendor is a core dependency.

## 4. Provider routing

Order is configurable (`ProviderRouter`), not hard-coded into biological
semantics. Default:

user_assertion → knowledge_mapping → association_guard → generative_provider

Failure never fabricates a sequence. Every invocation is a RouteStep.

## 5. Inverse-resolution model

Typed InverseResolution records association class, direction, licenses_inverse,
evidence_status, validation_status. Association/correlation stays E0010.
A future InverseStrategyProvider can license inverse mappings without editing
compiler core. Unsupported causality is not invented to pass tests.

## 6. Constraint graph

ConstraintGraph nodes + DEPENDENCY / JOINT / CONFLICT / PROVIDER_REQUIREMENT
edges. Statuses: ALL_RESOLVED, PARTIALLY_RESOLVED, DEPENDENCY_BLOCKED,
CONFLICTING, UNSUPPORTED. Independent per-constraint resolution from v0.7 is
preserved; the graph is an additional typed artifact.

## 7. Physical realization

LocalMockRealizationBackend emits PhysicalRealization with constructs, QC,
checksums, provenance. Statuses: REALIZED, REALIZATION_UNAVAILABLE,
REALIZATION_INVALID. Digital compilation is not physical execution.

## 8. Digital execution

SimulatorDigitalBackend wraps `python/panini/simulator`. ExecutionRun records
run_id, model, seed, history, events, phenotype, verification, twin descriptor.
S(t+Δt)=F(...); Φ(t)=H(S(t)) remains the declared model. Target satisfaction
is not biological validation.

## 9. Geometry / animation

Deterministic fixture backend: phenotype → point cloud + schematic fields.
Animation is a JSON frame sequence preserving time, state, observation,
geometry, provenance. Mesh/voxel/implicit implementations are declared, not
faked.

## 10. Observation / validation

Observation sources: SIMULATION, PHYSICAL_EXPERIMENT, MANUAL_ASSERTION,
EXTERNAL_DATASET. Pipeline: Observation → EvidenceRecord → ClaimEvaluation.
Statuses: NOT_VALIDATED, OBSERVED, SUPPORTED, VERIFIED, CONTRADICTED,
INCONCLUSIVE. History is appended.

## 11. Provenance

New artifacts carry digest + compiler/provider/model versions. Dual-path
ArtifactGraph is addressable from source to claim.

## 12. Fixture

`python/panini/fixtures_v08.py` — tiny synthetic cases (1–8) plus digital /
physical / geometry / validation tests. Not a real organism corpus.

## 13. Limitations

See the final report. Architecture is present; scientific datasets, causal
models, wet-lab adapters, and complete SBOL are absent by design.

## 14. Still requiring future scientific datasets/models

Real organism reference + annotation + causal knowledge; calibrated digital
twins; licensed inverse-causal mappings; experimental validation of compiled
ATGC; vendor synthesis adapters.
