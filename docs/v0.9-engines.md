## Classification

Every component is labelled CONTRACT / ADAPTER / FIXTURE / ENGINE / MODEL / PROVIDER.
A fixture is never reported as a scientific engine. SSA and GPU remain
scaffolded or unavailable unless they actually execute.

## Engines implemented against deterministic fixtures

- Multiscale state + transitions `X(t+Δt)=F(...)`
- Biochemical ODE (A→B→C)
- CPU reference execution protocol
- Spatial fields (sample/interpolate/gradient/laplacian/threshold/mask/combine)
- Reaction–diffusion
- Cellular substrate (signal, transition, division, death, migration)
- Developmental combination + maturation frames
- Phenotype engine with desired/predicted/observed separation
- Physiological tank fixture + plug-in slots
- Point cloud / voxel / parametric / mesh geometry
- Animation from trajectories + minimal glTF adapter
- Realization planning (plan/package/verify); labs stay adapters
- Reference genome engine (synthetic + retrieved loci)
- Sequence engine (canonical edit path + FASTA/GenBank-min)
- Generative candidate pipeline over provider abstraction
- Inverse strategy engine (synthetic license only)
- Constraint-graph solver → ResolutionPlan
- Class-separated coverage
- Cross-artifact verification
- Artifact-level debugger traces

## Explicitly not claimed

- CUDA GPU execution (detected UNAVAILABLE here)
- SSA / stochastic kinetics
- Causal genomic realization of two tails
- Validated mammalian biochemistry, physiology, or morphogenesis
- Inverse-causal knockout biology
- Quantitative genetics
